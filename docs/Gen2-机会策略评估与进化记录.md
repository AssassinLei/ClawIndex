# 机会策略评估、进化记录与跟踪结果修复

## 从目标推导规则

本系统的任务是从申万一级、二级行业里筛出值得进一步监控的方向。发现候选之后，实际跟踪哪个指数、持仓状态及买卖判断仍由“我的指数”和“今日操作”处理。

合理的筛选至少需要同时回答四件事：它自己有没有改善；是否比共同基准更强；风险是否可接受；是否只是把同一风险换了几个名字重复展示。不能因为排名总能排出第一，就每天必须给出机会。

旧版用自身60日正收益、相对沪深300表现、均线确认、估值及风险门槛筛选，允许结果为空，并把低估企稳放在观察层。这适合作为研究初筛。趋势的思路可以参考[Time Series Momentum 原始研究](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum)，但该研究的资产、周期和执行方法不同，不能据此证明本系统在A股行业指数上的60/120日参数有效。

经济意义上的投资机会还涉及未来盈利、价格中已反映的预期、估值和实际交易成本。现有雷达没有验证成分股盈利质量，也没有直接映射可交易基金，所以“估值低”不是内在价值的证明，“价格走强”也不是盈利增长预测。

## 本次已实现的修正

规则更新为`opportunity_radar_v2`，保留原有阈值，不通过本次历史筛选挑选“最好看”的参数。

| 问题 | 原行为 | 新行为与代价 |
| --- | --- | --- |
| 父子行业重复计票 | L1、L2混在一起算上涨行业占比，一个大行业的很多子行业可能放大市场强度 | 广度仅统计L1；L1历史覆盖不足80%或上涨占比低于40%，最多保留观察 |
| 回撤口径 | 当前点位距过去120日最高点的跌幅，反弹后会掩盖期间的大跌 | 检查120日窗口内按时间先后计算的最大收盘回撤；超过原20%门槛排除。可能排除已经反弹的行业 |
| 波动窗口过短 | 仅20日年化波动，近期平静可能掩盖稍早的大幅波动 | 同时检查20日与60日年化波动，沿用45%门槛；不是实际最大亏损保证 |
| 行业重复暴露 | 主要去掉父子指数和高相关候选，同一父级的两个子行业仍可能占多个名额 | 同一L1家族最多展示一个方向，同时保留120日相关性去重。也可能少展示同一家族内表现不同的机会 |
| 估值有效变化窗口不一致 | 分位取1250日，而不同估值数量统计全历史 | 两者统一使用最近1250个交易日；数据变化不足时不声称有估值依据 |

排名仍按入场确认、趋势类型、中期相对表现等既定顺序处理，不把多个高度相关指标重复计票，也不把排名转换成赚钱概率。数据缺口不填平；总覆盖不足时继续准备，允许没有候选。

## 证据和未完成的效果验证

使用本地2026-10-15的同一份只读行情快照对比v1/v2，扫描范围165个L1/L2，只有2个满足260个连续有效交易日要求：两版均处于准备阶段，均没有展示候选。这说明现有本地覆盖不足以证明哪版收益更好；这次对照是当前筛选核对，不是投资收益回测。

功能回归通过的含义是：回撤公式正确、不会用未来数据、行业不重复计数、记录和界面正常。它不验证未来盈利能力。

下一步应固定规则和当时可用的目录，按真实展示时间之后的下次开盘，分别跟踪观察候选、确认候选的20/60日净表现、同期基准、回撤、撤销和成本；跨牛熊阶段比较整个发现流程。不能用某个指数在“策略与进化”里的回测通过，替代发现排名本身的效果验证。对同一历史反复试参数会增加过拟合风险，可参考作者提供的[The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。

规则升级后，即使相同指数仍入选，也会为新版本建立独立跟踪记录。旧版本的首次展示、下跌、撤销和历史结果保留；样本可能重叠，不据此计算独立胜率。

## 进化记录怎么查看

进入“策略与进化”，选择指数，查看“进化记录”：

- 同时展示研究发起时间、参数实际生效时间，均为北京时间，包含完整年月日。
- 新记录区分手动进化并应用、手动提交研究、后台自动研究和手动回退；历史未保存发起来源的记录如实标注“未记录”。
- 用实际策略变更审计中的新旧版本比较参数，不用候选参数冒充已生效参数。
- 未通过、等待行情、模拟观察中的研究显示参数未变；查看详情时，候选差异单列为“尚未生效”。
- 实际应用展示均线、连续确认天数、均线变化窗口、因子组合等发生变化的参数；回退保留独立记录，不覆盖原应用时间。
- 可筛选手动/自动，或只看实际应用与回退。当前策略设置已停用时，历史仍可查看。默认最多最近250条，仅本账号可读。

## 跟踪结果为什么会消失

机会页面每5秒自动刷新。旧代码把表格放在“按钮本次被点击”的分支里；下一次刷新时按钮值恢复为假，表格随之消失。

现在将展开状态保存在当前账号的页面会话里：点击“查看展示后的跟踪结果”后，自动刷新继续显示，直到点击“收起跟踪结果”。没有历史记录时，空状态说明也持续显示。

## 关注一级指数、隐藏二级指数

看到二级机会后，如果希望跟踪其一级行业，可在“我的指数”搜索并添加对应L1，然后按L1自己的“今日操作”判断。L2满足条件不意味着L1也满足条件。

“暂不关注”是当前账号对该代码的持续隐藏，会影响该代码之后的候选展示和机会推送；不会更改筛选规则、停止已关注指数的巡检、训练策略或连带隐藏父级/兄弟指数。只是不准备这次买入时，可以保留候选。误点后到“我的隐藏列表”恢复。

## 部署

代码更新无需数据库结构迁移或重新初始化：

```bash
cd ~/ClawIndex-Gen2 &&
sudo bash deploy.sh update &&
sudo bash deploy.sh status
```

更新会自动重启服务。规则版本变化后，旧机会快照会先标为等待更新，后台用同一数据维护流程生成v2快照；数据覆盖未达门槛时继续准备。
