# 历史曲线：使用与设计

## 为什么这样放

用户看到买卖判断后，通常先想知道价格最近怎么走、为什么触发规则，然后才会继续查看估值、成交和专业指标。历史曲线因此放在原有判断与证据旁边，默认只画收盘点位与该次规则的均线，不增加新的必经操作。

| 入口 | 用途 | 使用的数据 |
| --- | --- | --- |
| 今日操作 → 指数卡片 → 查看曲线 | 从当前判断直接查看走势 | 该次巡检保存的行情、规则与交易日历 |
| 今日操作 → 查看数据，或信号详情 → 查看数据与判断依据 → 查看历史曲线 | 将曲线与指标数值、规则依据对照 | 该次巡检保存的数据 |
| 我的指数 → 选择指数 → 查看历史曲线 | 不必先巡检，日常查看已经同步的走势 | 后台已同步且已完成时段的最新可用行情，以及当前规则 |
| 操作记录 → 查看某次巡检的历史曲线 | 复看过去判断时的走势，停止关注后仍可查询 | 所选巡检保存的数据，后续补数、修订与规则进化不覆盖它 |

## 怎么用

默认打开“价格与均线”，看收盘相对规则均线的位置。可在“叠加曲线”里增加20、60、120、250日均线；规则使用其他天数时，也会提供该条规则均线。

“显示范围”提供近1月、近3月、近1年、近3年与全部，默认近1年；“全部”是当前这份数据实际保存的历史。范围以图表所注明的行情截止日计算，复看旧巡检时不会被今天的日期截成空白。鼠标移到曲线上可查看当日数值。

通过“曲线指标”切换：

- **阶段涨跌幅**：近5、20、60个交易日的指数点位涨跌。
- **估值**：正市盈率、正市净率、估值历史分位、点位历史分位。
- **成交与风险**：成交额及20日均值、成交活跃度、20日年化波动、距120日高点跌幅。
- **规则依据**：规则均线变化、连续高于或低于均线的交易日数。
- **市净率÷市盈率**：明确标为推算比值，不当作真实披露的净资产收益率。
- **更多基础与专业指标**：选择当前数据实际包含的换手率、MACD、相对强弱、布林通道等指标，每次单独展示一种，避免不同单位混在同一纵轴。

展开“查看曲线数据并导出”可核对逐日数据，下载当前范围的CSV。百分比列使用百分数，例如12.5代表12.5%；成交额只使用已确认人民币单位的数据，转换为亿元；专业指标沿用接口口径。

## 保证曲线与证据一致

1. **先计算，后截取。** 均线、波动、估值分位沿用巡检的`feature_frame`公式与规则参数，使用完整已保存历史计算，再按显示范围裁切。切换近1月不会把120日均线变成只有一个月的均线。
2. **只用当时及之前的数据。** 估值分位的每个历史点只使用截至当日的窗口。巡检图表读取保存的`datasets.manifest`与原规则，不读取后续行情修订。若未来算法版本改变，会明确提示派生指标可能与旧算法不同。
3. **按交易日保留缺口。** 行情先对齐该市场交易日历，缺失交易日不填平。图表给缺口两边分配不同线段，避免连成连续走势；休市日不当作缺失交易日。
4. **口径如实标注。** “距120日高点跌幅”不是期间最大回撤；点位历史分位不是估值结论；指数涨跌不是基金或账户收益。不把规则曲线标成真实成交。
5. **缺失不冒充零。** 海外接口未提供估值或专业因子时显示原因与空状态，适用数据由后台既有流程维护。新版没有可靠无风险利率序列，因此不生造旧版风险溢价曲线。

## 持续运行与权限

图表使用Streamlit已有绘图能力，无需新增云端服务、网络请求或生产依赖。折叠时不加载图表数据，完整历史的计算结果按数据内容及规则缓存；原始数据或规则改变后使用新缓存。查看图表不会提交同步、巡检或AI任务。

今日操作、信号详情保持原有自动刷新，图表的显示状态、指标与范围不会因普通刷新消失。数据来源和截止日期始终显示。曲线查询校验当前账号和所选巡检所属账号，不能访问朋友的私人策略记录。

更新无需迁移或初始化数据库：

```bash
cd ~/ClawIndex-Gen2 &&
sudo bash deploy.sh update &&
sudo bash deploy.sh status
```

## 验证范围

专项测试覆盖公式与巡检一致、完整历史预热、无未来数据、交易日缺口分段、百分比与金额单位、旧证据不被行情修订或策略进化覆盖、账号隔离、空数据、全部指标类型的图表结构、四个页面入口、自动刷新保留选择，以及打开图表不新增任务或AI解读。另使用隔离的合成数据库在真实Chrome中核对1440像素宽屏和390像素窄屏布局与图表实际渲染。测试环境不使用生产数据库或真实接口。
