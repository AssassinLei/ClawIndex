# 策略与进化：怎么用

**策略就是“满足什么条件买、满足什么条件卖”的规则。进化就是定期检查，这套规则有没有值得改进的地方。**

目标是尽量减少大幅回撤，接受可能少赚；历史筛选和模拟结果不能保证未来表现。

## 系统帮你做什么

1. **用过去行情比较**：在限定范围内，比较现行规则与候选规则的回撤、收益代价和交易频率。
2. **给新规则一个试用期**：候选通过历史检验后，用之后新出现的行情模拟买卖，不动用真实资金。
3. **达标后按授权更换**：观察也通过、你已允许自动更换，并满足更换间隔等条件，才更新规则。没有合格改进时，继续用原规则。

这些步骤由程序按固定标准执行，AI不决定如何改规则。

## 你需要做什么

- **日常**：看“今日操作”，不需要每天来改参数。
- **首次设置**：决定是否允许系统在达标后自动更换规则。不授权时也可以自动研究，并继续用原规则生成判断。
- **想自动更换**：在开始研究前展开“调整自动进化设置”，审阅范围，勾选允许自动更新，确认后保存。不是点一下立即换策略。
- **其余时间**：看页面上的“现在的进度”和“你现在要做的”。行情缺口由后台自动补，无需手动补数据或反复点击研究。

自动更换不会自动下单。外部提醒还要求规则已启用提醒、通知渠道已开启。

## 看见这些状态怎么办

| 页面状态 | 含义与操作 |
| --- | --- |
| 等待开始研究 / 正在比较新规则 | 后台检查条件或分批研究，通常无需操作 |
| 新规则正在模拟试用 | 继续观察，当前仍用原规则，不用真实资金 |
| 本轮未找到合格改进 | 保留原规则，下一轮按计划研究 |
| 新规则已通过观察 | 已授权则继续检查更新条件；未授权则保留原规则 |
| 新规则已投入使用 | 回“今日操作”查看新规则产生的判断 |
| 自动研究已暂停 | 希望继续时，在设置中开启并保存 |
| 本轮研究未完成 | 查看失败原因；后台持续异常时到“系统状态”排查 |

默认研究至少间隔30个自然日，候选模拟试用需63个**新交易日**，约3个月。真实时长还取决于数据、交易次数等条件；不能用过去的日期补算试用。

## 设置为什么不建议反复改

真正改变参数、研究范围或授权，会使原候选结束，按新设置重新检验。包括先不授权、观察通过后再改成允许自动更换的情况，因此最好在开始研究前决定授权方式。

**重复保存完全相同的配置会保留研究进度。** 页面会明确告知“设置未变化，当前研究与观察进度已保留”。

“手动检查研究”只在需要立即提交时使用；不会绕过检验条件或直接更换规则。手动研究、因子诊断和完整版本证据仍放在高级入口，平时无需逐项阅读。
