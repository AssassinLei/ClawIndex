# 新版快速上手

适用于VNext 2.1。Linux云端运行、自动维护与因子进化详见[当前版本手册](VNext-云端自动维护与因子进化-2026-10-13.md)。本地更新后重新运行“一键启动新版.bat”；没有旧窗口时会核验并清理本项目遗留服务。保留启动窗口。

## 第一次用

1. 输入固定账号名登录。原有账号继续用原名字，不需要密码。
2. 在“监控与数据”确认已有关注指数；已有电池、机器人等监控不用重复添加。
3. 未登记持仓默认空仓。真实持有时在“持仓与预算”改为持有，金额与份额可留空，无需每周复核。
4. 后台自动维护行情、补历史并生成“今日操作”；需要立即刷新时仍可提交巡检，原有进度弹窗保留。

## 平时用

- 日常看“今日操作”，历史缺口和适用的专业因子由后台自动补充，无需逐个同步。
- 先看行情日期，再看“针对你的判断”及下面的原因；“上次结果”不能当作当前判断。
- 想看AI解释，可勾选“巡检时同时生成AI解读”，或在结果卡片下点击“生成AI解释”。需要AI密钥，可能消耗模型额度。解读保存后再打开仍可看到。
- 买卖在自己的基金平台完成；之后重新确认持仓，并在“历史与反馈”记录执行情况。没有交易也至少每7天重新确认持仓。

## 自动更新和提醒

后台运行时，工作日默认自动更新所有用户关注的指数。同一个指数共享行情，无需每个人重复拉取。每天按各市场已经收盘并达到预期发布时间的交易日更新，接口延迟会重试；当日未发布时，前一交易日可能就是最新可用行情。

自动更新行情与自动分析/提醒是两个设置。管理员在“通知与运行”维护；你的通知渠道独立开关。自动更新不代表所有结果卡片已重新分析，页面会提示较早结果需要重新巡检。正式提醒仍要求规则已启用、数据通过、持仓有效、个人判断为买入/卖出，并且渠道已开启。

## 遇到问题

| 页面提示 | 怎么处理 |
| --- | --- |
| 后台尚未就绪 / 排队中 | 确认使用一键启动且窗口仍运行。请求已保存，恢复后台后继续处理 |
| 行情接口未配置或权限不足 | 检查新版`.env.next`的Tushare Token及接口权限，修改后重启 |
| 预期交易日数据尚未提供 | 稍后重试，不把旧数据当作今天的新信号 |
| 历史数据不足 | 在“监控与数据”填写较早的起始日期，补历史后重新巡检 |
| 请确认持仓或资金 | 在“持仓与预算”确认真实状态；金额可先留空 |
| AI暂不可用，使用程序解读 | 信号不受AI失败影响；检查模型配置，或稍后点“生成AI解释”重试 |

进度弹窗可关闭，任务仍在后台继续。结果页自动刷新，健康页可查看错误及处理自己的待执行任务。系统帮助识别规则条件，不保证收益，不自动下单。
