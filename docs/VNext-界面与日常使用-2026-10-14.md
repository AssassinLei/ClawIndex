# VNext 2.3：界面与日常使用

这次改动围绕一个问题：用户每天只愿意花几分钟，打开系统后怎样知道该做什么？

因此，界面按“结论 → 原因 → 详细证据”展示，把参数和排查工具收进次级入口。页面层级、明确标签与表单反馈参考 [W3C 页面结构指引](https://www.w3.org/WAI/tutorials/page-structure/)。

## 每天怎么用

1. 登录后看 **今日操作**。先看“待你处理”的数量，买卖判断排在前面；正常持有、空仓等待放在“持续跟踪”。
2. 想了解原因，点卡片里的 **查看数据** 或 **查看解读**；解读会标明 **AI生成** 或 **程序生成**。读完可点 **收起详情**。过期结果会明确提示，不能当作当前操作。
3. 实际买卖后，展开 **记录我的处理结果**。可以只记处理结果，也可明确勾选同步确认成交后的持仓。

行情和判断仍由后台自动更新。需要立即检查时点 **提交全部巡检**；AI默认开启，开关放在 **巡检选项** 中。当天有效结果仍会复用。

## 各入口做什么

| 现在的入口 | 主要用途 | 对应原入口 |
| --- | --- | --- |
| 今日操作 | 每日待办、数据与AI分析、处理结果 | 今日操作 |
| 我的指数 | 添加指数、查看维护进度、停止关注 | 监控与数据 |
| 我的持仓 | 修改空仓或持有状态，可选补充金额与预算 | 持仓与预算 |
| 策略与进化 | 看研究和观察进度，需要时修改授权范围 | 策略与研究 |
| 操作记录 | 查询历史判断、按指数筛选、补记处理结果 | 历史与反馈 |
| 信号详情 | 对照指数信号、个人判断及完整证据 | 信号与待执行 |
| 通知与设置 | 开关提醒渠道、管理后台更新 | 通知与运行 |
| 系统状态 | 查看后台连接、运行记录和任务明细 | 健康 |

## 如何区分内容来源

- **AI生成的解读**：摘要、反面观点、分析局限及情景说明由AI根据程序证据生成。
- **程序生成的解读**：摘要和风险说明来自程序固定模板，不是AI生成的内容。
- **程序生成的解读（AI未成功）**：AI调用或校验未成功，当前展示程序的备用解读；失败原因另行说明。

每张首页卡片会在展开前显示当前解读来源。买卖判断、参考金额和数据判断依据均由程序规则产生，并各自标注来源。尚未生成解读或来源无法确认时，会明确说明，不标成AI结果。

新账号没有指数时，首页会直接引导添加第一个指数。未登记持仓默认空仓，实际持有时再修改；市值、份额、预算与真实基金映射都可按需填写。

## 策略页面的变化

优先展示自动研究、生成判断和自动更新规则的当前状态，再展示研究或观察进度。尚未保存的配置显示“待初始化”，不会把表单默认值说成已经生效。

页面补充“我该怎么用？”、“现在的进度”和“你现在要做的”，并区分当前设置与此前设置的研究记录。重复保存完全相同的设置会保留进度。简明解释见[策略与进化怎么用](VNext-策略与进化怎么用.md)。

平时无需逐个调整参数。确实需要修改时展开 **调整自动进化设置**；手动研究、发布规则仍保留在 **高级：手动研究与规则配置**。自动晋升的原有授权要求保留。

## 显示和部署

- 统一青绿色主按钮、卡片、字号与留白。买入、卖出、等待既有文字也有样式区分。
- 手机下导航收起，卡片与按钮适应窄屏；详情中的表格可在表格内部滚动。
- 正常后台任务只显示简短进度，任务明细按需展开；离线、重试仍明确提示。
- 首页不再重复渲染整套信号详情，完整分析使用独立页面。
- 视觉样式位于 `clawindex_next/ui_design.py`，主题位于 `.streamlit/config.toml`；Docker镜像会包含主题配置。

本次无需数据库迁移。更新代码并重启页面服务后刷新浏览器即可；云端沿用现有 Docker Compose 更新方式，首次包含主题配置时需要重新构建镜像。交易规则、自动进化检验与通知授权流程保持原有实现。

## 开发验收预览

运行 `python scripts/preview_next_ui.py --port 8876`，用账号“界面体验”登录。

此入口使用临时数据库与合成行情，关闭数据接口和模型密钥，不启动后台、不创建通知渠道。演示心跳只用于展示正常连接的界面，不能作为实际后台运行证明。退出预览进程会停止页面并清理临时库。
